# 🍔 Online Burger Ordering System

A responsive front-end web application developed using **HTML5** and **CSS3** that provides an attractive and user-friendly interface for browsing a restaurant menu and placing burger orders.

This project demonstrates fundamental web development concepts, responsive design principles, and clean user interface design.

---

## 📌 Project Overview

The Online Burger Ordering System is a static website that simulates an online food ordering platform. It allows users to explore the menu, view burger options, and navigate through a modern restaurant-style interface.

---

## ✨ Features

- 🍔 Attractive homepage
- 📋 Interactive burger menu
- 📱 Responsive design for different screen sizes
- 🎨 Modern UI with CSS styling
- 🖱️ Easy navigation
- ⚡ Fast loading static website

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/vijayalakshmi10103/burger-ordering-system.git
```

2. Open the project folder.

3. Double-click **index.html**

OR

Open the folder in Visual Studio Code and launch it using the **Live Server** extension.
